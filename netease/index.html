浏览器直连 music.163.com 会被 CORS 和 Referer 校验拦掉，所以必须要有一个代理。 默认的 /api 就是本站自带的那个 —— 它随站点一起部署在 Cloudflare Pages 上， 跟页面同源，不用配任何东西。想换成自己另外部署的 Worker 或者 Netease_url 服务， 把地址填在这里就行；它只存在你自己的浏览器里（localStorage），不会上传到任何地方。 也可以用 ?api= 参数临时指定，例如 ?api=https://xxx.workers.dev。 Browsers cannot call music.163.com directly — CORS and the Referer check block it, so a proxy is required. The default /api is the built-in one: it deploys with this site on Cloudflare Pages and is same-origin, so it needs no configuration. To use a separately deployed Worker or a Netease_url service instead, put its address here — it is kept in your own browser (localStorage) and never uploaded. You can also pass it per-visit with ?api=https://xxx.workers.dev.
