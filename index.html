01 / 强化学习Reinforcement Learning

DQN 贪吃蛇DQN Snake

用 Java Swing 写的贪吃蛇当作环境，通过 TCP Socket 把 47 维状态传给 Python 侧的 PyTorch 智能体，用 Double DQN 训练它自己找食物、躲墙、少绕圈。 A Java Swing Snake game acts as the environment; a PyTorch agent learns Double DQN over a 47-dim state streamed through a TCP socket, teaching itself to find food, avoid walls and stop looping.

  • Double DQN + 优先经验回放（按 TD 误差采样）+ 目标网络Double DQN with prioritized replay (TD-error sampling) and a target network
  • ε 从 1.0 衰减到 0.03；每 8000 步自动存档模型与经验池ε decays 1.0 → 0.03; model and replay buffer auto-saved every 8,000 steps
  • 检测并惩罚重复状态，抑制原地绕圈Repeated states are detected and penalised to stop it looping in place

Java Swing · TCP Socket · Python · PyTorch

02 / 自动驾驶Autonomous Driving

BeamNG 自动驾驶BeamNG Autopilot

基于 BeamNG.drive + BeamNGpy 的自动驾驶研究项目，按感知 / 决策 / 控制分层；规则驾驶那层已经在山地路线跑通，现在把结构对齐特斯拉 FSD 的分层数据流。 An autonomous driving research project on BeamNG.drive + BeamNGpy, layered as perception / decision / control; the rule-based layer already completes mountain routes, and the stack now mirrors Tesla FSD’s layered data flow.

  • 8 路环视相机 + HydraNet 多任务感知：语义分割 / YOLO 目标 / 交通灯 / 车道拓扑8-camera ring with a HydraNet multi-task head: segmentation / YOLO objects / traffic lights / lane topology
  • BEV 占用栅格 + 向量空间：地面反投影、log-odds 融合、时序滤波抑制幻影墙BEV occupancy grid and vector space: ground reprojection, log-odds fusion, temporal filtering against phantom walls
  • 分层规划：候选轨迹扇、走廊连通性门控、真曲率限速 + 12m 前瞻；规则层山路完成度 94.6%Layered planning: trajectory fan, corridor gating, true-curvature speed limits + 12 m lookahead; rule layer: 94.6% mountain-route completion

BeamNG.drive · BeamNGpy · YOLOv8 · Stable-Baselines3

03 / 音频分析Audio Analysis

音频可视化监听器Audio Visualizer

抓电脑正在播放的声音做实时可视化，不用选文件、也不用装虚拟声卡——能听到什么就画什么。 Real-time visualisation of whatever the computer is playing: no file picking, no virtual audio cable — if you can hear it, it gets drawn.

  • WASAPI 环回采集：Float32、自动适配 48k/96k/192k、32768 采样环形缓冲WASAPI loopback capture: Float32, auto-adapting to 48k/96k/192k, 32,768-sample ring buffer
  • FFT 2048–16384 点汉宁窗 + 对数频谱柱与峰值保持；波形自动增益FFT 2,048–16,384 point Hann window with log-frequency bars and peak hold; auto-gain waveform
  • numpy 整帧绘入 RGB 缓冲上屏，两张画布各 30Hz 交替刷新，远程桌面下也不掉帧Whole frames drawn into an RGB buffer with numpy; two canvases alternate at 30 Hz each and hold up over remote desktop

WASAPI Loopback · FFT · numpy · CustomTkinter

04 / 开发工具Developer Tool

DSH 用量统计插件DSH Usage Plugin

给 DeepSeek Harness 写的 Token 用量统计插件，侧边栏入口加模态面板；在官方统计之上补了工作区分组、按用量排序和子代理用量合并。 A token-usage plugin for the DeepSeek Harness, opened from the sidebar; on top of the official stats it adds workspace grouping, sorting by usage and sub-agent merging.

  • 一键幂等安装脚本：必要时给宿主打 7 个补丁、注册插件、构建，重复运行安全One-shot idempotent installer: applies 7 host patches when needed, registers the plugin and builds
  • 修掉一个真实数据缺陷：fork / 延续会话把父历史重复计入，宽时间窗下虚高 2.4 倍Fixed a real data bug: forked or continued sessions re-counted inherited history, inflating wide windows by up to 2.4×
  • 按 seedLength / session-end-seed 划定归属边界，每个会话只计自有调用Ownership is bounded by seedLength / session-end-seed so a session only counts its own calls

TypeScript · DeepSeek Harness

05 / 桌面工具Desktop Tool

屏幕使用时间记录Focus Time Tracker

Python 写的 Windows 桌面工具，每 2 秒采样一次前台窗口，把花在软件、游戏和网站上的时间记进 SQLite，再用浅色界面和图表复盘一天。 A Python desktop tool for Windows that samples the foreground window every 2 seconds, records time spent in apps, games and websites into SQLite, then reviews the day in a light-themed UI.

  • 只用标准库 ctypes 调 Win32 API 采样；分类优先级：手动覆盖 > 游戏规则 > 网站 > 应用Samples the foreground window with nothing but the stdlib (ctypes); order: manual override > game rules > website > app
  • 游戏按启动器 / 安装目录关键字识别（Steam / Epic / 战网 / WeGame 等），规则写在 JSON 里可改Games recognised by launcher/install-dir keywords (Steam / Epic / Battle.net / WeGame …), rules in an editable JSON file
  • 网站靠窗口标题 + 浏览器历史库本地匹配（Chrome / Edge / Firefox），全程不联网；SQLite WAL 支持读写并发Websites matched locally via window title + browser history (Chrome / Edge / Firefox), never online; SQLite WAL for concurrent reads

Python · Win32 API · SQLite
