№ 02 v0.5.0

AudioTransfer Studio

STM32 蜂鸣器的示例永远是单音 demo。我想让它唱一首完整的歌——有人声、有换气、有间奏的那种。

  • Demucs 分离人声，RMVPE + CREPE 双模型交叉校验音高
  • 连续旋律路径判定：换气不接伴奏、颤音不碎成新音符
  • 自动生成 STM32 固件并一键烧录，六首完整录音统一验证并留档
8.3k行 Python6首全曲验证1键烧录

模型权重是 CC BY-NC-SA，所以这个项目明确标注非商用。

№ 03 成熟

Focus Time Tracker

想知道时间到底去哪了，但不想把屏幕使用记录交给任何一家云。

  • Win32 API 采样前台窗口，纯 ctypes，零第三方采集依赖
  • 游戏按「启动器 / 安装目录」规则引擎识别；网站读浏览器本地历史库匹配
  • SQLite WAL 本地存储 + 托盘常驻，CI 跑 Python 3.10/3.12 矩阵
7.4k行 Python686个应用识别100%本地，不联网

所有数据都在本机一个 SQLite 文件里，删掉即消失。
